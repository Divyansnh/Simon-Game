## 🎯 Project Overview

This project demonstrates front-end development skills through a sophisticated implementation of the classic Simon memory game. Built with modern web technologies, it showcases:

- **Clean, maintainable code architecture**
- **Interactive user experience**
- **Multiple game modes**
- **Sound integration**
- **Responsive design**

The game challenges players to remember and repeat increasingly complex sequences, testing memory and cognitive skills while providing an engaging gaming experience.

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software installation required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Divyansnh/Simon-Game.git
   ```

2. **Navigate to project directory**
   ```bash
   cd Simon-Game
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your preferred browser
   # Or use a local server for development
   python -m http.server 8000  # Python 3
   # or
   npx serve .                 # Node.js
   ```

4. **Start playing!**
   - Click the "Start" button to begin
   - Follow the on-screen instructions

## 🎮 How to Play

### Basic Gameplay
1. **Start the Game** - Click the "Start" button in the center
2. **Watch & Remember** - Observe the sequence of colored lights
3. **Repeat the Pattern** - Click the buttons in the same order
4. **Progress** - Each successful round adds one more step
5. **Challenge** - The game ends if you make a mistake

### Controls
- **Start Button** - Begin a new game or reset current game
- **Mode Button** - Switch between game modes (Classic → Speed → Reverse)
- **Sound Button** - Toggle audio effects on/off
- **Help Button** - View game instructions
